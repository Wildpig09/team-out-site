# Team Out – nouveau site (prototype)

Refonte du site [team-out.be](http://team-out.be/fr/), spécialiste du team building outdoor en Belgique.

## Prototype de la page d'accueil

Trois directions de design, avec le contenu et le logo du site actuel :

- **A – Corporate épuré** : `prototype/accueil/variante-a.html`
- **B – Nature premium** : `prototype/accueil/variante-b.html`
- **C – Moderne & dynamique** : `prototype/accueil/variante-c.html`

Pour les voir : télécharger le dépôt et ouvrir `prototype/accueil/index.html` dans un navigateur.
La barre en bas de l'écran (ou les flèches ← → du clavier) permet de passer d'une variante à l'autre.

Ce code est un prototype jetable : il sert à choisir une direction, pas à être mis en ligne tel quel.
